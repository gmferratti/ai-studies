# Aprendizado Não Supervisionado

Algoritmos que buscam estrutura em dados sem rótulo: agrupamento, regras de
associação e redução de dimensionalidade.

## Algoritmos

- [ ] Clustering: k-means e hierárquico (`clustering/clustering.py`)
- [ ] Regras de associação: Apriori (`apriori/apriori.py`)
- [ ] Redução de dimensionalidade: PCA (`pca/pca.py`)

## Comparação de resultados

Ainda sem algoritmo treinado nesta família. A tabela é preenchida conforme
cada um for implementado; como são tarefas diferentes (agrupar, achar
regras, reduzir dimensão), cada uma deve usar as métricas que fazem sentido
pra ela, não uma tabela única de acurácia/precisão/recall/F1 como na família
supervisionada.
